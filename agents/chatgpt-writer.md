# Writing guide (sample)

Instructions for the AI assistant that drafts chapters of this book. Replace this file with your
own book's guide; Book Builder includes it in every writing prompt.

- Write for the reader named in `research/03-content-outline.md`.
- Use plain language: short sentences, one idea per paragraph, terms explained when first used.
- Follow the chapter's outline entry. Don't add chapters or topics the outline doesn't list.
- Cite sources from `references.bib` with Pandoc citations, for example `[@sample2026]`.
  Never invent a source; mark claims that need one with `[source needed]`.
- Keep the terms in `research/continuity.md` consistent.
- Return the whole chapter as Markdown with its front matter unchanged.
