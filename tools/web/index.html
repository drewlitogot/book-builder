      How a chapter goes
        
            
      1. Research: copy the research prompt into a new ChatGPT chat (web search on). Import the ZIP it makes (from Downloads), or copy its reply and save it. Simple chapters can skip research.
        2. 
            
      2. Write: copy the writing prompt into the same chat.
        3. 
            
      3. Save: use the copy button under ChatGPT's reply, then Save reply. The reply is checked first: right chapter, complete, boxes intact, not a duplicate.
        4. 
            
      4. Check: copy the check message and paste it into Claude Code.
        5. 
            
      5. Revise if Claude asks, in the same chat, then save the new reply.
        6. 
            
      6. Approve when Claude says it's ready.
      
            
      The big button on each chapter always does the next step.
      
          
      Batch: many chapters at once
      Pick a range, then go through the four steps: copy research prompts, save research, copy writing prompts, save drafts. The button does the highlighted row and moves down. Ranges must be chapter numbers from 1 to the last chapter, first to last.
      
          
      Build, save and publish
        
            
      • Build makes the PDF, EPUB, HTML and Word files in dist/. Contents: Simple lists parts and chapters; bookmarks still list every section.
        • 
            
      • Save work (More menu) commits on this computer, or commits and pushes to GitHub. Nothing happens until you press a button.
        • 
            
      • Website: Check, then Preview, then Publish. Only approved chapters and games are published; it asks before publishing.
      
          
      Games
      Copy the game prompt for an approved chapter, paste it into ChatGPT, copy the reply and Import from clipboard. ChatGPT also makes two image sheets and an icon; choose them when asked. Games stay in review until you preview and approve them.
      
          
      ChatGPT setup
      
            
      Nothing to set up: every Copy button gives a complete prompt. ZIP buttons also download reference files to attach. For shared background across chats, set up a Project in ChatGPT workspace.

      Common problems
        
            
      • “The clipboard is empty”: in ChatGPT use the copy button under the reply, then try again.
        • 
            
      • “This looks like another chapter”: you copied a reply from a different chat. Open the chat named for this chapter.
        • 
            
      • Reply cut off: type “continue” in ChatGPT, then copy the complete reply.
        • 
            
      • No research ZIP found: it must be in Downloads and named like ch05-research.zip; or save the reply text instead.
        • 
            
      • Game image sheet too small: ask ChatGPT for the sheet at its highest resolution.
        • 
            
      • Publish failed: read the log, fix the problem and press Publish again; nothing partial goes live.
