# Templates

Structural starting points. Replace every `REPLACE` and change `id`, `chapter` and `authors`.

- `minimal-package/`: one info screen, one question with nuanced feedback, one completion screen.
- `branching-package/`: a scenario with selectable cards, a branch rule, a variable, a perspective screen,
  a slider and a conditional (never saved) written reflection, ending with a summary.
- `reflection-package/` (API 1.1): a ranking with shuffle and a hint, personalized text, feedback on the
  top-ranked choice, and a completion screen with takeaways and Save my notes.

All three validate as they are, so you can import one to see how the runtime looks before writing content.
They are not chapter activities and must not be published.
