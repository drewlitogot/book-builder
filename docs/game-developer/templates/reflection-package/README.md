# Reflection package (API 1.1)

A complete, valid example of the features new in Game API 1.1:

- a `ranking` field with `shuffle` and a `hint`;
- personalized text with `{{answer:priorities}}`;
- feedback that reacts to the top-ranked option with the `first` condition;
- a completion screen with `takeaways` and `allowSaveNotes` (needs the `save-notes` capability).

Copy the folder, change every value, and keep `"apiVersion": "1.1"` in both files.
